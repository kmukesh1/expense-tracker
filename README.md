# Expense Tracker

A beautiful, modern, and fully functional **Expense Tracker** web application built with HTML, Tailwind CSS, and JavaScript.

## Features

- Add, edit, and delete expenses
- Quick add form + detailed modal
- Spending breakdown with interactive doughnut chart
- Smart filters (search + category)
- Summary statistics (Total, This Month, Avg/Day)
- Export to CSV
- Dark mode support
- Data saved automatically in browser (localStorage)
- Fully responsive design

## Live Demo

Visit the live version here: https://kmukesh1.github.io/expense-tracker

## How to Use

1. Open `index.html` in any browser
2. Add your expenses using the Quick Add panel or the "Add New Expense" button
3. View your spending patterns in the chart
4. Use search and filters to find old transactions
5. Export your data anytime as CSV

## Tech Stack

- HTML5
- Tailwind CSS (via CDN for simplicity)
- Chart.js
- Vanilla JavaScript

## Getting Started (Local)

Just open the `index.html` file in your browser. No build step or server required.

## Deployment

This app is deployed using **GitHub Pages**.
